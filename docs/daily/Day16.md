# Day16

## 오늘 한 일

Kaggle Store Sales - Time Series Forecasting **기존 최고 모델의 품목별 오차 분석, 학용품 급증과 Lag 참조 시점 비교, 33개 품목의 유형 분류, 보류 품목의 전체 기간 패턴 분석, 1번 그룹 전용 Lag16 통제 실험 설계**

- 기존 최고 CV 후보인 **Trial17 / Base23 + Lag364 + Lag28**을 기준으로, 평균 점수 뒤에 어떤 품목별 실패가 있는지 살펴봤다.
- 이미 저장된 검증 예측과 판매 데이터를 활용했다. 필요한 날짜·품목 집계는 다시 학습하지 않고도 확인할 수 있었다.
- 학용품·사무용품의 판매 급증 시기와 현재 Lag가 참조하는 날짜를 직접 비교했다. **급증을 놓친 결과를 단순히 ‘오차가 크다’에서 끝내지 않고, 모델이 실제로 보고 있던 정보와 연결했다.**
- 오차가 큰 품목을 하나씩 끝없이 튜닝하기보다 **단기 변화 / 안정·장기 흐름 / 현재 모델 적합 / 별도 집중 검토**의 네 유형으로 나누기로 했다.
- 통계 기준으로 1·2·3 후보를 만들고, 분류 보류였던 네 품목은 상세 수치와 그래프로 추가 확인했다.
- **란제리·여성의류·가정주방 I·식료품 II는 서로 다른 이유로 4번 집중 검토 대상**으로 정했다. 특수 원인을 모두 확정했다는 뜻은 아니다.
- 다음 실험은 **기존 공통 모델에 `group1_lag16` 한 개만 추가**하는 것으로 좁혔다. 모델 분리, 그룹 카테고리 추가, Lag7 추가는 이번 실험에서 제외했다.
- 전체 실험 코드는 작성하고 문법을 확인했다. **이 회고 작성 시점에는 새 Lag16 실험의 학습·CV 결과가 아직 확인되지 않았다.**

### 3. 학용품·사무용품 — 급증 시기와 Lag가 보는 과거의 불일치

전체 54개 매장의 학용품 일별 합계에서 7월 21일 무렵 증가가 보였고, 7월 28~30일에 급격히 커졌다.

| 날짜 | 실제 판매 | 기존 예측 | Lag28 참조일 → 실제 판매 | Lag364 참조일 → 실제 판매 |
|---|---:|---:|---|---|
| 2017-07-21 | 285 | 약 42 | 2017-06-23 → 51 | 2016-07-22 → 27 |
| 2017-07-30 | 2,027 | 약 306 | 2017-07-02 → 153 | 2016-07-31 → 112 |
| 2017-08-06 | 5,415 | 약 1,078 | 2017-07-09 → 117 | 2016-08-07 → 319 |
| 2017-08-15 | 2,530 | 약 1,027 | 2017-07-18 → 54 | 2016-08-16 → 656 |

- 모델 입력은 매장·품목별 Lag이며, 표는 설명을 위해 전체 매장 값을 합산한 것이다.
- **7월 21일의 증가가 Lag28에 들어오는 것은 8월 18일부터**다. 현재 검증 마지막 날인 8월 15일까지 Lag28은 그 증가를 직접 전달하지 못한다.
- Lag364가 보는 작년 같은 요일의 판매량도 올해보다 훨씬 작았다. 다만 작년 급증 시기가 달랐는지까지 이 날짜 비교만으로 확정할 수는 없다.
- Lag16이라면 7월 21일 정보가 8월 6일부터 전달된다. 최근 변화 반영을 앞당길 가능성은 있지만 **급증 시작을 미리 예측해 주는 피처는 아니다.**
- 매장별 보조 분석에서는 Quito·Ambato 일부 매장의 큰 증가를 확인했다. Fold3에서 전 구간보다 일평균이 증가한 매장은 30/54개, 10개 넘게 증가한 매장은 12개였다.
- 이후 분석은 **품목별 특성을 중심으로 진행**하기로 했다. 매장 차이는 품목 합계가 특정 매장에 좌우되거나 패턴을 가리는지 확인하는 보조 관점으로 남겼다.

### 4. 33개 품목을 유형별로 묶기 — 숫자 기준과 판단의 역할 분리

오차가 큰 품목을 모두 개별 튜닝하면 시간이 오래 걸리므로, 먼저 비슷한 문제를 가진 품목끼리 묶어 거시적인 개선 가능성을 확인하기로 했다.

**수치 계산 기준**

| 항목 | 기준 |
|---|---|
| 분석 단위 | 품목별 전체 매장 하루 판매 합계 |
| 평소 단기 변동 | 각 Fold 시작 전 1년의 `abs(log1p(sales_t) - log1p(sales_t-7))` 평균 |
| 큰 단기 변동 | 전체 33개 품목 중 상위 25% |
| 작은 단기 변동 | 전체 33개 품목 중 하위 50% |
| 최근 급변 | Fold 직전 7일 평균 ÷ 그 이전 28일 평균이 1.5 이상 또는 2/3 이하 |
| 비율 계산 가능 | 7일·28일 관측이 모두 있고, 기준 28일 하루 평균이 1 이상 |
| 현재 모델 적합 후보 | 세 Fold 모두 품목 RMSLE ≤ 해당 Fold 전체 RMSLE |

**후보 판정 순서: 3번 → 1번 → 2번 → 판단 보류**

- **3번:** 세 Fold 모두 상대적으로 잘 맞추는 품목.
- **1번:** 3번이 아닌 품목 중, 한 Fold라도 변동 상위 25% 또는 최근 급변에 해당하는 품목.
- **2번:** 앞선 후보가 아닌 품목 중, 세 Fold 모두 변동 하위 50%이고 최근 급변이 없으며 비율 계산이 가능한 품목.
- 위 조건에 해당하지 않으면 보류한다. 중간 수준의 변동과 높은 오차가 함께 있는 품목은 기준 사이에 남을 수 있다.
- 사분위와 급변 경계는 **이번 프로젝트의 운영 기준**이며 통계적으로 검증된 정답은 아니다. 네 유형을 사분위 네 구간으로 나눈 것도 아니다.

초기 코드는 `numeric_candidate`에 후보를 출력하고, 그래프 확인 내용을 `review.csv`에 입력해야 `classification`을 확정하는 구조였다. 따라서 **최초 실행에서 최종 분류가 전부 ‘판단 보류’였던 것은 수동 확인값이 없었기 때문**이다.

- ‘반복해서 놓치는 패턴이 없음’은 처음부터 자동으로 계산된 조건이 아니었다.
- 대화 중 제안된 **3회·75%·오차 1.5배 기준은 기존 코드에 구현된 조건이 아니다.** 해당 기준으로 분류를 완료한 것처럼 기록하지 않는다.
- 코드를 받았을 때 결과 표만 보는 것이 아니라 **실제로 어떤 조건이 구현됐는지 확인해야 한다**는 점을 배웠다.

### 6. 전체 기간 그래프와 변동성 — 큰 진폭과 불규칙성은 다름

란제리·여성의류, 식료품 II·가정주방 I를 두 쌍으로 나누어 전체 기간 통계와 그래프를 확인했다.

- 전체 판매량, 28일 이동평균, 각 품목의 평균을 100으로 맞춘 상대 추이를 비교했다.
- 일별·같은 요일·주간·월간 변화율과 이동 CV를 계산했다.
- 연도별 월간 패턴과 요일별 평균을 확인하고, 큰 변화가 발생한 날짜도 별도로 저장했다.

| 품목 | 전체 일평균 | 전체 CV | 2017년 일평균 | 2017년 CV | 전체 판매 0 비율 |
|---|---:|---:|---:|---:|---:|
| 란제리 | 388 | 0.300 | 379 | 0.229 | 16.0% |
| 여성의류 | 387 | 0.985 | 648 | 0.426 | 59.8% |
| 식료품 II | 1,166 | 0.366 | 1,390 | 0.291 | 12.1% |
| 가정·주방용품 I | 1,105 | 0.795 | 1,823 | 0.330 | 34.6% |

※ CV는 표준편차÷평균. 2017년은 1월 1일~8월 15일만 포함한다. 판매 0 비율은 매장×날짜 관측 기준이다.

**품목별 관찰과 판단**

- **여성의류:** 2013년 판매 기록이 모두 0이고, 2014~2015년에도 0 구간의 영향이 컸다. 2016~2017년에는 일별 진폭은 크지만 반복 형태가 비교적 일정해 보였다. ‘변동성이 없다’보다 **‘진폭은 크지만 패턴이 일정할 수 있다’**고 해석했다.
- **란제리:** 그래프에서 연도별 비슷한 패턴이 관찰됐다. 일평균은 2013년 452 → 2016년 301로 내려갔고, 2017년 관측 기간에는 379였다. 반복 패턴과 장기 수준 변화를 함께 확인할 대상으로 정했다.
- **가정·주방용품 I:** 2013년 전체 판매 기록이 0이다. 전체 CV는 0.795지만 2015~2017년 CV는 약 0.33~0.36이다. 초기 구간을 포함한 통계만으로 지속적으로 불안정한 품목이라 판단하면 부정확하다.
- **식료품 II:** 2017년 그래프가 이전 연도와 다른 양상을 보인다고 판단했다. **‘패턴 변화 의심’**으로 기록하고, 판매 수준 차이인지 패턴 형태의 변화인지 같은 월·기간으로 다시 비교하기로 했다.

**분석의 한계**

- 여성의류·가정주방 I의 0은 실제 미판매, 미취급, 기록 문제 중 무엇인지 확인되지 않았다. 바로 삭제하거나 결측으로 바꾸지 않는다.
- 전체 기간 통계는 과거의 수준 변화·판매 0 구간까지 포함한다. 현재 예측에 중요한 최근 기간의 특성과 구분해야 한다.
- 단순 변화율은 분모가 작으면 커지고, 0이면 정의되지 않는다. 여성의류 676일, 가정주방 I 522일의 일별 변화율이 미정의였으며, 이 수치는 누락 날짜 수가 아니라 **분모 0·결측·첫날 등이 포함된 결과**다.
- 분석 원본에는 달력상 누락일이 4일 있었고 이를 0으로 채우지 않았다. 모델 파이프라인의 날짜 복원 처리와 구분한다.
- 전체 매장 합계의 변화와 매장별 RMSLE는 집계 단위가 다르다. 합계에서 안정적으로 보여도 매장별 오차는 클 수 있다.

### 7. 현재 전체 품목 분류와 결정

| 분류 | 개수 | 품목 |
|---|---:|---|
| **1. 단기 변화 대응형 후보** | **7** | 미용용품, 철물류, 가전제품, 잔디·정원용품, 주류·와인·맥주, 잡지, 학용품·사무용품 |

| **3. 현재 구성 적합형 후보** | **16** | 유아용품, 음료, 도서, 빵·베이커리, 청소용품, 유제품, 델리, 달걀, 냉동식품, 식료품 I, 가정관리용품, 육류, 개인관리용품, 가금류, 조리식품, 농산물 |

| **합계** | **33** | |

- 1·2·3은 수치 기준의 **후보 상태**를 유지한다. 4번은 상세 분석 후 별도 검토하기로 정한 대상이다.
- 가정주방 I은 **0 구간의 의미와 처리 방식을 확인한 뒤 재분류**한다.
- 2번이라고 Lag28·요일·일자 피처를 바로 제거하지 않는다. 같은 요일 사이 변화가 작아도 주말마다 반복되는 큰 변화는 존재할 수 있다.
- 2번의 향후 가설은 하루 값보다 평균적인 판매 수준을 제공하는 것이다. 예측 시점에 알 수 있는 자료로 만든 평균 피처를 추가하고, 필요하면 그다음에 Lag28 제거를 별도로 비교한다.

### 8. 그룹별 피처 적용 방식 — 공통 모델 유지

처음에는 1번 전용 모델을 분리하는 방법도 논의했다. 모델을 나누면 품목별로 해당 모델의 예측을 만든 뒤 행 순서에 맞춰 합칠 수 있지만, **전용 모델이 다른 품목의 학습 사례를 활용하지 못한다**는 단점이 있다.

이번 실험은 모델 분리 효과를 섞지 않기 위해 **전체 품목을 함께 학습하는 공통 모델을 유지**한다.

```python
df["group1_lag16"] = df["sales_lag_16"].where(
    df["family"].isin(group1_families)
)
```

- 모든 행에 동일한 열을 만들고, 1번 품목에는 Lag16 값을, 나머지에는 `NaN`을 둔다.
- 일반 `sales_lag_16`은 모델 입력 목록에 추가하지 않고 **마스킹된 열만 추가**한다.
- 이 코드는 행마다 피처를 켜고 끄는 기능이 아니다. LightGBM은 값의 분기 기준과 결측값 경로를 학습한다.
- 따라서 **1번에만 Lag16 값을 제공하지만, 예측 영향이 1번에만 제한되는 것은 아니다.** 다른 그룹의 성능도 함께 확인한다.
- 기존 `family`가 있고, 마스킹된 열의 값 유무로도 1번과 나머지가 구분된다. 이번에는 **1·2·3·4 카테고리 피처를 추가하지 않는다.**

## 판단 / 배운 점

### 1. 전체 최적 피처가 모든 품목의 최적 피처는 아니다

- 현재 Lag28·Lag364 조합이 전체 기준에서 좋더라도 학용품 급증이나 일부 품목의 반복 패턴을 충분히 반영하지 못할 수 있다.
- 그렇다고 전체 피처를 바로 바꾸거나 품목마다 모델을 늘리기보다, **그룹별 가설을 최소 변경으로 검증**하는 것이 현재 프로젝트에 맞다.

### 2. 예측 실패를 이해하려면 Lag가 실제로 보는 날짜를 확인해야 한다

- 급증 시점과 참조 날짜를 나란히 놓으니 왜 최근 증가 정보가 입력에 들어가지 않았는지 이해하기 쉬웠다.
- Lag16은 정보 전달을 앞당길 수 있지만 미래 사건을 예고하지 않는다. **변화 감지와 변화 예측은 다른 문제**다.

### 3. 큰 변동폭, 불규칙성, 장기 수준 변화는 구분해야 한다

- 큰 진폭이 일정하게 반복되는 품목과 예측하기 어려운 불규칙 품목은 같지 않다.
- 초기 판매 0 구간이 길면 전체 기간 CV가 커질 수 있다. 연도별·최근 기간을 함께 봐야 한다.
- 같은 요일 간 변동 지표는 주간 반복 패턴을 어느 정도 제거한 지표라, 단순 일별 진폭과 다른 결론이 나올 수 있다.

### 4. 총량이 맞아도 개별 예측은 틀릴 수 있다

- 여성의류의 전체 판매량은 2.5% 과소였지만 Fold별로 방향이 달랐고 RMSLE는 높았다.
- 과대·과소가 합계에서 상쇄되는 현상을 고려해야 한다. 합계 편향, 매장별 RMSLE, 기간별 패턴을 구분해서 읽는다.

### 5. 코드에 실제 구현된 기준과 설명에서 제안한 기준은 다를 수 있다

- `numeric_candidate`와 `classification`의 차이를 이해했고, 자동 계산 부분과 사람의 판단을 기다리는 부분을 구분했다.
- `pivot`은 매장별 Fold 값을 나란히 놓고, `map`은 매장 키에 맞는 값을 연결하며, `where`는 조건에 따라 값을 유지하거나 결측으로 바꾼다는 점을 확인했다.
- `last`는 Fold3 표에 붙인 변수 이름이지 특별한 명령어가 아니다. 요약 JSON은 이미 계산한 핵심 수치를 저장하는 역할이다.
- AI가 작성한 코드도 조건과 출력의 의미를 직접 확인해야 한다. **설명이 명확하지 않은 부분을 질문하고 수정하는 과정 자체가 학습**이었다.

### 6. 일부 품목에 값을 주는 것과 그 품목에만 영향을 주는 것은 다르다

- `group1_lag16`의 비대상 행은 NaN 경로를 따라가며, 모델 재학습으로 다른 품목의 예측도 바뀔 수 있다.
- 그룹 카테고리를 추가해도 모델이 반드시 그룹부터 분기하는 것은 아니다.
- 따라서 피처 적용 범위만 보지 않고 **전체·각 그룹의 결과를 함께 검증**해야 한다.

### 느낀 점

- 처음에는 모든 과정을 직접 실행하고 결과를 복사해서 정리하는 것이 실력 향상에 더 도움이 된다고 생각했다. 하지만 반복 집계와 시각화를 맡기면 생각할 시간을 훨씬 확보할 수 있다는 것을 느꼈다.
- 직접 해야 할 핵심은 모든 버튼을 누르는 것보다 **왜 이 실험을 하는지, 어떤 입력을 쓰는지, 결과로 어디까지 말할 수 있는지 이해하는 것**이라고 생각하게 됐다.
- 하나를 깊게 파는 과정에서 배운 것은 많지만, 프로젝트의 현재 위치와 다음 행동이 흐려지는 문제가 있었다. 이번에는 품목 그룹과 실험 순서를 정하면서 범위를 줄이려 했다.
- 동시에 숫자로 분류했다고 모든 판단이 끝난 것은 아니었다. 보류 품목을 그래프로 보니 초기 0 구간과 반복 패턴처럼 통계 한두 개로 설명되지 않는 부분이 드러났다.
- 코드를 그냥 실행하기보다 분기·마스킹·집계 방식을 계속 질문하면서, 내가 무엇을 이해했고 무엇을 아직 모르는지 확인할 수 있었다.
- 처음 접하는 개념은 직접 이해하고 확인하되, 이해한 반복 작업은 자동화하는 방식으로 진행하고 싶다. 추천시스템과 더 넓은 개발 역량을 쌓기 위해서도 **분석의 깊이와 프로젝트를 끝내는 경험을 함께 가져가야 한다.**
- **한 줄 정리: 모든 품목을 끝없이 개별 튜닝하기보다, 실패의 유형을 묶고 입력 정보와 연결한 작은 실험으로 검증하자.**

   - 이미 완료된 RF·기본 CatBoost 비교는 활용하고, 새로운 설정이나 튜닝의 목적을 분명히 한다.

4. **최종 후보 검증·제출·문서화**
