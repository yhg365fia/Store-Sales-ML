## 확인 범위와 남은 한계

- 이번 결과는 **현재 로컬 후보의 입력·설정·저장 예측 정합성 확인**이다. 다시 학습해 같은 예측값이 나왔다는 뜻은 아니다. 재학습을 남은 필수 작업으로 다시 제안하지 않는다.
- 현재 후보에는 Oil·Transactions가 입력되지 않는다. 이 후보의 검사 통과를 과거 외부 피처 실험 전체의 누수 검증 완료로 확대하지 않는다.
- CV는 튜닝·조기 종료에 사용됐다. 2016년 백테스트도 선택 조건에 따라 진단용이며 손대지 않은 최종 평가가 아니다.
- 7,418회는 Trial17 Fold2·3 Best Iteration 평균을 반올림한 기존 선택이다. 이번 검사는 이 선택이 최적이라는 증명이 아니다.
- 과거 Public **0.42832**는 고정 파라미터·3,407회 모델이다. 최신 Trial17·7,418회 모델의 Public 점수로 옮겨 적지 않는다.
- 기본 CatBoost 혼합도 저장 결과에서 확인했다. 3-Fold 평균 LightGBM **0.390752**, 기본 CatBoost **0.433903**이며 10% 간격 혼합은 단독 LightGBM보다 평균 악화. **CatBoost Optuna 코드가 있다는 사실만으로 튜닝 완료라고 기록하지 않는다.**
- 검사 대상 로컬 소스는 GitHub src보다 최신이며 변경 중인 파일이 있다. 이를 덮어쓰거나 현재 GitHub src와 동일하다고 기록하지 않았다. 실제 점검 파일은 [해시 기록](provenance.json)으로 식별하며 로컬 audit_outputs/source_snapshot에 보존했다.
